# Fotky poslancov

Sem patria fotky poslancov, na ktorých zverejnenie máte súhlas.

- Názov súboru: `<PoslanecID>.jpg` (ID z nrsr.sk, napr. `1008.jpg`), štvorcový formát, ideálne 400 × 400 px.
- Stránka ich zobrazí automaticky po najbližšom nasadení; poslanci bez fotky majú iniciály.
- Zdroj fotiek uveďte v `src/pages/o-projekte.astro` (sekcia Fotografie).
